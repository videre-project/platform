# @videreproject/sql-builder

Typed SQL fragments, predicates, filters, JSON helpers, and schema utilities used by Videre services.

The package is distributed as ESM with generated TypeScript declarations:

```sh
pnpm add @videreproject/sql-builder
```

This package is part of the Videre Project and is released alongside `@videreproject/constants` and `@videreproject/ui` from a shared Git tag.
