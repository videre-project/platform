# `@videreproject/sql-schema`

Generated database schema types and typed table references for Videre services.

The PostgreSQL schema is derived from the [`mtgo-db`](https://github.com/videre-project/mtgo-db) project's SQL tables. Regenerate this package from the monorepo root with the below commands:

```sh
pnpm db:generate-types
pnpm db:check-types
```
